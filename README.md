# Handmade Greeting Card

&nbsp;

## 1\. Description

&nbsp;

A handmade greeting card created using colored paper and simple decorative materials. It is designed to convey a short message in a creative and attractive way.

## 2\. Required Materials

Colored paper

Scissors

Glue

Sketch pen/marker

Decorative paper

Pencil and ruler

## 3\. Procedure

Select a suitable colored sheet and determine the required card size.

Fold the sheet accurately along the center to form the card structure.

Measure and cut decorative paper according to the required dimensions.

Arrange the decorative pieces on the front surface before applying glue.

Fix the decorative elements using glue and allow them to dry properly.

Add suitable patterns or handmade decorations to improve the visual appearance.

Write an appropriate greeting message neatly inside the card.

Inspect the completed card for proper alignment, firm attachment, and neat finishing.

## 4\. Working Principle

The card is constructed using paper folding, cutting, layering, and adhesive joining techniques. The folded sheet provides the basic structural support, while additional colored papers and decorative elements create the desired visual design.

## 5\. Notes

Make the folds neat and straight.

Use scissors carefully.

Apply glue properly without excess.

Keep the decorations simple and attractive.

Ensure the card opens and closes easily.
